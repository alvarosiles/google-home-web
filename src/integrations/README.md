# src/integrations

Integraciones externas. Cada subcarpeta traduce el modelo genérico de automatización a una plataforma concreta.

- `shared/` — contratos/interfaces comunes a toda integración.
- `google-home/` — primera integración soportada (ver [docs/google-home.md](../../docs/google-home.md)).

Ver [docs/integrations.md](../../docs/integrations.md) para cómo agregar una nueva plataforma.
